Nothing happens when I click Start the app

The button uses the link healthreport://start. Windows must be told once what that link does.

  1. Close this page. In the app folder, open the launcher folder and double-click register_link.cmd. It needs no administrator rights.
  2. Open this page again and click Start the app.
  3. Your browser asks whether to open the link. Choose to allow it. This question appears because the browser, not this page, controls what a link can start.

A command window opens and keeps the app running. Close that window to stop the app. The app then opens in a new browser tab.
